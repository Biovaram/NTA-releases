# NTA

Downloads for the NTA desktop app: nanoparticle tracking analysis for ZetaView
and Malvern Zetasizer data, with quality control, statistics and an AI
measurement assistant.

## Download

Get the latest version from **[Releases](../../releases/latest)**:

| System | File |
| --- | --- |
| Windows 10/11 | `NTA-Setup-<version>.exe` |
| macOS (Apple silicon) | `NTA-<version>-arm64.dmg` |

**Windows:** run the installer. If Windows shows "Windows protected your PC",
choose **More info → Run anyway**.

**macOS:** open the `.dmg` and drag NTA into Applications. The first time you
open it, macOS blocks it; go to **System Settings → Privacy & Security** and
choose **Open Anyway**.

## Updates

NTA checks for new versions when it starts. When one is available it asks
before updating: Windows installs it and restarts, macOS opens the new
download.

## AI assistant

Add your Gemini API key in **Settings → AI assistant**
([get one here](https://aistudio.google.com/apikey)). It is stored on your
computer only.
